  year: string;

  subtitle: string;

  What is the purpose of app/layout.tsx in the Next.js App Router?
  It produces the layout of the app and it is shared between pages. The layout does not change and it is not
  reloaded. It is used for fix parts of the webpage like header, footer and navigation bar.

  Why are the components in this assignment Server Components rather than Client Components?
  They are server components so the data fetching happens in the backend, saving time and adding security.
  Because everything happens in the backend the  UI shows a page that has been pre-rendered and there is less JavaScript loaded to the 
  client's browser. This also improves the SEO.
